# =============================================================================
# FASTAPI SERVICE RUNTIME DEPENDENCIES
#
# This file contains dependencies required to run the current FastAPI service.
#
# Active infrastructure:
#
# - FastAPI
# - Uvicorn
# - Pydantic 2
# - SQLAlchemy 2 async
# - MySQL through asyncmy
#
# Currently disabled integrations are retained as commented references:
#
# - PostgreSQL
# - MongoDB
# - Redis
# - Microsoft SQL Server
# - Celery
#
# This is the single source of truth for production Python dependencies.
# ``pyproject.toml`` contains tool configuration and package metadata only; it
# does not declare or install application dependencies.
#
# Install active runtime dependencies with:
#
#     python -m pip install --requirement requirements.txt
#
# Do not uncomment optional drivers unless their corresponding configuration,
# registry integration, health checks, and tests have also been enabled.
# =============================================================================


# =============================================================================

# =============================================================================

# MySQL is the currently active database integration.

#     mysql+asyncmy://username:password@hostname:3306/database_name

# =============================================================================

# =============================================================================

# =============================================================================
# TIMEZONE SUPPORT
# =============================================================================

# Windows installations may not include the IANA timezone database required by
# Python's zoneinfo module.
#
# Linux Docker images usually provide timezone information through the
# operating system, so this dependency is installed only on Windows.
tzdata>=2025.2; platform_system == "Windows"

# =============================================================================
# MICROSOFT SQL SERVER — CURRENTLY DISABLED
#
# SQLAlchemy asynchronous MSSQL access can use ``aioodbc`` with ``pyodbc``.
#
# Installing these Python packages is not sufficient by itself. The operating
# system must also contain a compatible Microsoft ODBC driver, such as:
#
#     ODBC Driver 18 for SQL Server
#
# Uncomment only after:
#
# 1. MSSQL settings are enabled in ``app/core/config.py``.
# 2. The MSSQL adapter is enabled in ``app/db/registry.py``.
# 3. The Docker image installs the Microsoft ODBC system packages.
# 4. MSSQL readiness checks and integration tests are enabled.
#
# Example SQLAlchemy URL:
#
#     mssql+aioodbc://username:password@hostname:1433/database_name
#     ?driver=ODBC+Driver+18+for+SQL+Server
#     &TrustServerCertificate=yes
# =============================================================================

# aioodbc>=0.5,<1.0
# pyodbc>=5.2,<6.0
